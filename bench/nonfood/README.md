# Non-meal photos (benchmark phase n)

Photos the app must not log as a meal (#49). Labels are in `NON_MEALS` in `bench/ground_truth.py`;
run them with `bench/run.py --phase n`. They hold no GPS tags, so unlike `test_pictures/` they are
committed.

`black-frame.jpg` was generated for this benchmark (a camera that fired in a pocket). The others
